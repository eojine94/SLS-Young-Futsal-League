# SLS FUTSAL LEAGUE PRD v1.2

> 풋살 리그 정보 확인 서비스

## 1. 제품 개요

### 1.1 문제 정의

풋살 리그를 운영하고 있지만, 순위·일정·경기 결과 등을 모두 수기로 정리하고 문서로 관리하고 있다. 리그 참가자나 관심 있는 사람들이 리그 정보를 확인할 수 있는 서비스가 없다.

### 1.2 해결 방법

풋살 리그 정보 확인 서비스를 웹으로 만들어서, 리그에 참여하는 사용자를 포함한 모든 사람들이 리그 순위·일정·결과를 확인할 수 있도록 한다. 관리자는 리그 데이터를 등록·관리할 수 있다.

### 1.3 타겟 사용자

| 구분 | 설명 |
|------|------|
| 일반 사용자 | 풋살 리그에 참여하는 선수 및 리그에 관심 있는 모든 사람 |
| 관리자 | 리그를 운영하며 팀·일정·결과를 등록·관리하는 운영자 |

### 1.4 서비스 형태

- 모바일 앱 스타일 웹 (고정 폭 레이아웃)
- PC: 화면 중앙에 모바일 앱 크기(max-width: screenMaxWidth)로 표시, 양옆 여백
- 모바일: 화면 전체를 차지
- 관리자 페이지도 동일 웹앱 내에서 권한 기반으로 분기

### 5.1 일반 사용자

| 탭 | 아이콘 | 화면 |
|----|--------|------|
| 홈 | 🏠 | Home |
| 순위 | 🏆 | Rank |
| 경기 | ⚽ | Match |

### 5.2 관리자

| 탭 | 아이콘 | 화면 |
|----|--------|------|
| 홈 | 🏠 | Home |
| 순위 | 🏆 | Rank |
| 경기 | ⚽ | Match (일정 등록·수정 + 결과 등록) |
| 팀 | 👥 | Team (팀/선수 관리) |

### 5.3 관리자 로그인 접근

- 일반 사용자 화면(Home, Rank, Match)의 헤더 우측 상단에 열쇠 아이콘(🔑)이 표시된다.
- 열쇠 아이콘을 탭하면 관리자 로그인 화면으로 이동한다.
- 로그인 성공 시 하단 네비게이션에 관리자 전용 탭(팀)이 추가로 표시된다.

### 5.4 관리자 로그아웃

- 관리자로 로그인한 상태에서 일반 사용자 화면(Home, Rank, Match)의 헤더 우측 상단에 열쇠 아이콘(🔑) 대신 로그아웃 아이콘(🔓)이 표시된다.
- 로그아웃 아이콘을 탭하면 로그아웃되며, 하단 네비게이션에서 관리자 전용 탭(팀)이 제거된다.
- 로그아웃 후 열쇠 아이콘(🔑)이 다시 표시된다.

### 6.0 Login (관리자 로그인)

관리자 기능에 접근하기 위한 로그인 화면이다.

**레이아웃**

- 화면 좌측 상단에 뒤로 가기 버튼(← 아이콘)이 표시된다.
- 화면 중앙에 로고(SLS FUTSAL LEAGUE)와 "관리자 로그인" 텍스트를 표시한다.
- 로고 하단에 로그인 폼을 표시한다.

**입력 항목**

| 항목 | 타입 | 필수 |
|------|------|------|
| 이메일 | 이메일 입력 | O |
| 비밀번호 | 비밀번호 입력 | O |

**기능**

- 뒤로 가기 버튼: 이전 화면으로 돌아간다.
- Supabase Auth를 사용한 이메일/비밀번호 로그인
- 로그인 성공 시 홈 화면으로 이동하며, 하단 네비게이션에 관리자 전용 탭(팀)이 추가되고, 경기 화면에서 일정 수정·결과 등록 기능이 활성화된다.
- 로그인 실패 시 에러 메시지 표시

**레이아웃**

**사용처**

### 6.1 Home

홈 화면은 리그의 핵심 정보를 한눈에 보여주는 대시보드 역할을 한다.

#### 6.1.1 순위 조회 영역

**레이아웃**

- 상단에 "팀별" / "개인별" 2개의 필터 박스가 가로로 나란히 배치된다.
- 필터 박스는 네모 형태의 토글 버튼이며, 선택된 항목은 포인트 컬러로 활성화된다.
- 필터 하단에 순위 리스트가 표시된다.

**데이터 규칙**

- 상위 3개 데이터만 표시한다.
- "상위"의 기준:
  - 팀별: 승리 수가 많은 순서
  - 개인별: 득점 수가 많은 순서
- 동점일 경우 이름(팀명 또는 선수명) 가나다순으로 정렬한다.

**팀별 필터 선택 시 리스트 항목**

- 표시 정보: 팀명, 승리 수

**개인별 필터 선택 시 리스트 항목**

- 표시 정보: 등번호. 이름 (예: 0. 홍길동), 팀명, 득점 수

**기본값**: 팀별 필터 활성화 상태

**더보기**

- 순위 리스트 카드 하단에 "더보기" 버튼이 표시된다.
- "더보기"를 탭하면 Rank 화면(6.2)으로 이동한다.

---

#### 6.1.2 경기 일정 영역

**레이아웃**

- 순위 영역 하단에 배치한다.
- 상단에 "다음 경기" 섹션 타이틀을 표시한다.
- 날짜 헤더 하단에 경기 카드 리스트가 표시된다.

**데이터 규칙**

- 현재 시점 기준으로 가장 가까운 미래 날짜의 경기를 모두 표시한다.
- 해당 날짜에 경기가 여러 개면 모두 표시한다.

**날짜 헤더**

```
── 2025.02.15(토) ──
```

**리스트 항목 (카드형)**

- Match 화면과 동일한 MatchCard 컴포넌트를 사용한다.
- 대진(팀 A vs 팀 B), 시간(HH:mm), 장소를 카드 형태로 표시한다.

### 6.2 Rank

순위를 전체적으로 상세 조회할 수 있는 화면이다.

#### 6.2.1 레이아웃 및 플로우

- 화면 상단에 가이드 텍스트를 표시한다. (예: "리그 팀 순위", "팀을 클릭하면 팀 내 선수 순위를 볼 수 있습니다.")
- 화면 진입 시 팀별 순위 테이블이 표시된다.
- 팀을 클릭하면 해당 팀의 개인별 순위(팀 상세)로 이동한다.

#### 6.2.2 팀별 순위 테이블

| 칼럼 | 설명 |
|------|------|
| 순위 | 승리 수 기준 순위 |
| 팀명 | 팀 이름 |
| 경기 | 총 경기 수 |
| 승 | 승리 수 |
| 무 | 무승부 수 |
| 패 | 패배 수 |

- **정렬**: 승리 수 내림차순 (고정)
- 동점 시 팀명 가나다순
- 무승부 판정: 두 팀 점수가 동일한 경우

#### 6.2.3 팀 상세 (개인별 순위)

팀을 클릭하면 해당 팀의 선수 목록이 개인별 순위로 표시된다.
상단에 가이드 텍스트를 표시한다. (예: "팀 내 선수 순위", "골 수 기준으로 정렬됩니다.")

| 칼럼 | 설명 |
|------|------|
| 순위 | 골 수 기준 순위 |
| 이름 | 등번호. 이름 형식 (예: 0. 홍길동) |
| 골 | 개인 득점 수 |
| 도움 | 개인 도움 수 |

- **정렬**: 골 수 내림차순 (고정)
- 동점 시 이름 가나다순
- 팀명은 헤더에 이미 표시되므로 각 행에 표시하지 않는다

### 6.3 Match (경기)

경기 일정과 결과를 통합하여 조회하는 화면이다. 일반 사용자와 관리자 모두 접근 가능하다.

#### 6.3.1 경기 조회 (일반 사용자 + 관리자)

**레이아웃**

- 화면 상단에 가이드 텍스트를 표시한다.
  - **일반 사용자**: "경기", "모든 경기 일정과 결과를 확인할 수 있습니다."
  - **관리자**: "경기", "예정된 경기를 탭하면 일정을 수정하고, 완료된 경기를 탭하면 결과를 등록할 수 있습니다."
- 전체 경기를 날짜별로 그룹핑하여 리스트 형식으로 표시한다.
- 과거 경기(결과)와 미래 경기(일정)를 하나의 타임라인으로 시간순 정렬한다.
- 기본 스크롤 위치: 가장 가까운 미래 날짜의 경기가 화면 중앙에 오도록 스크롤한다.
- 홈팀/원정팀 구분 없이, 두 팀의 대진만 표시한다.

**일반 사용자 vs 관리자**

- **일반 사용자**: 경기를 조회만 할 수 있다. 경기 항목을 탭해도 아무 동작이 없다.
- **관리자**: 다음의 추가 기능이 제공된다.
  - 가이드 텍스트 타이틀 우측에 "경기 등록" 버튼이 표시된다.
  - 경기 등록 버튼을 탭하면 일정 등록 화면(6.3.2)으로 이동한다.
  - score가 null인 경기를 탭하면 일정 수정 화면(6.3.3)으로 이동한다.
  - score가 등록된 경기를 탭하면 결과 수정 화면(6.3.4)으로 이동한다.
  - 경기 날짜가 현재 시점보다 과거이면서 score가 null인 경기에는 "결과 등록 필요" 태그를 표시한다.

**날짜 헤더**

```
2025.02.15(토)
```

**리스트 항목 (카드형)**

- MatchCard 컴포넌트를 사용한다.
- 대진(팀 A vs 팀 B), 시간(HH:mm), 장소를 카드 형태로 표시한다.
- 결과가 등록된 경기는 스코어(예: 3:1)를 포인트 컬러로 표시한다.
- 결과 미등록 경기는 스코어 없이 표시한다.

#### 6.3.2 일정 등록 (관리자 전용)

관리자로 로그인한 경우, 경기 화면 가이드 텍스트 타이틀 우측에 "경기 등록" 버튼이 표시된다.
버튼을 탭하면 일정 등록 화면으로 이동한다. 헤더에 "일정 등록"이 표시된다.

**입력 항목**

| 항목 | 타입 | 필수 |
|------|------|------|
| 팀 A | 셀렉트 (등록된 팀 목록) | O |
| 팀 B | 셀렉트 (등록된 팀 목록) | O |
| 날짜 | 날짜 선택 | O |
| 시간 | 시간 선택 | O |
| 장소 | 텍스트 입력 | O |

**유효성 검사**

- 팀 A와 팀 B가 동일하면 등록 불가
- 모든 필수 항목 입력 확인

#### 6.3.3 일정 수정/삭제 (관리자 전용)

관리자가 예정된 경기를 탭하면 일정 수정 화면으로 이동한다. 헤더에 "일정 수정"이 표시된다.
입력 항목과 유효성 검사는 일정 등록(6.3.2)과 동일하며, 기존 데이터가 미리 채워진 상태로 표시된다.

**기능**

- 저장: 일정 정보 변경
- 일정 삭제: "일정 삭제" 버튼(빨간색 Destructive)을 탭하면 삭제 확인 다이얼로그(6.0.1)가 표시된다. 확인 시 일정이 삭제되고 경기 목록으로 돌아간다.

#### 6.3.4 결과 등록/수정 (관리자 전용)

관리자가 경기를 탭하면 결과 등록/수정 화면으로 이동한다.
헤더에 "결과 등록"(score가 null) 또는 "결과 수정"(score가 존재)이 표시된다.
상단에 가이드 텍스트를 표시한다. (예: "경기 결과 등록", "팀 스코어와 선수별 기록(골, 도움)을 입력하세요.")
이미 결과가 등록된 경기는 기존 데이터(스코어, 선수 기록)가 미리 채워진 상태로 표시된다.

**경기 정보 표시**

- 날짜, 시간, 장소를 상단에 표시한다. (예: "2025.02.15(토) 14:00 마포풋살장")

**팀 스코어 입력**

- 대진 정보 표시: {팀 A} vs {팀 B}
- 팀 A 점수 입력 (숫자)
- 팀 B 점수 입력 (숫자)

**선수별 기록 입력**

- 팀 A / 팀 B 각각의 섹션으로 구분하여 표시한다.
- 각 섹션 헤더에 "{팀명} 기록" 타이틀과 "+ 기록 추가" 버튼이 표시된다.
- "+ 기록 추가"를 탭하면 선수 선택 바텀시트가 올라온다.
- 각 선수 행에 삭제(✕) 버튼이 표시된다.

**선수 선택 바텀시트**

- 반투명 오버레이 배경 위에 바텀시트 형태로 표시된다.
- 바텀시트 헤더: "선수 선택" 타이틀 + 닫기(✕) 버튼 + 안내 문구 (예: "{팀명}에서 기록할 선수를 선택하세요.")
- 해당 팀의 선수 목록이 리스트로 표시된다.
- 선수를 선택하면 해당 행이 확장되어 골/도움 스테퍼 입력이 표시된다.
  - 골: −/+ 스테퍼 (기본값 0)
  - 도움: −/+ 스테퍼 (기본값 0)
- 선택된 선수는 체크 아이콘으로 표시, 미선택 선수는 빈 원 아이콘으로 표시된다.
- 하단에 "선택 완료" 버튼이 표시된다.
- 선택 완료 시 결과 등록 화면의 기록 리스트에 선수가 추가된다.

**입력 항목 정리**

| 항목 | 타입 | 필수 |
|------|------|------|
| 팀 A 점수 | 숫자 입력 | O |
| 팀 B 점수 | 숫자 입력 | O |
| 선수 기록 (팀 A) | 선수 선택 + 골 수 + 도움 수 | X |
| 선수 기록 (팀 B) | 선수 선택 + 골 수 + 도움 수 | X |

**유효성 검사**

- 팀 점수는 0 이상의 정수
- 개인 골 합계가 팀 점수와 일치하는지 확인 (경고 표시, 등록은 가능)

**등록 완료 시**

- 순위 테이블에 자동 반영 (팀 승/패, 득점, 개인 골/도움 등)

### 6.4 Team (관리자 전용)

팀과 선수를 관리하는 화면이다. 관리자 네비게이션에만 표시된다.

#### 6.4.1 팀 목록

- 등록된 팀을 리스트로 표시한다.
- 각 팀을 탭하면 팀 상세(선수 관리) 화면으로 이동한다.
- "팀 추가" 버튼으로 새 팀 생성 가능

**팀 목록 리스트 항목**

- 팀명
- 선수 수

#### 6.4.2 팀 생성

팀 목록 화면에서 "팀 추가" 버튼을 탭하면 팀 생성 화면으로 이동한다. 헤더에 "팀 생성"이 표시된다.
상단에 가이드 텍스트를 표시한다. (예: "새 팀 등록", "팀명을 입력하여 새로운 팀을 등록하세요.")

**입력 항목**

| 항목 | 타입 | 필수 |
|------|------|------|
| 팀명 | 텍스트 입력 | O |

**유효성 검사**

- 팀명은 필수 입력
- 기존 팀과 동일한 팀명 불가

#### 6.4.3 팀 수정

선수 관리 화면(6.4.4) 헤더의 설정(⚙️) 아이콘을 탭하면 팀 수정 화면으로 이동한다. 헤더에 "팀 수정"이 표시된다.
상단에 가이드 텍스트를 표시한다. (예: "팀 정보 수정", "팀명을 수정하거나 팀을 삭제할 수 있습니다.")
입력 항목은 팀 생성(6.4.2)과 동일하며, 기존 데이터가 미리 채워진 상태로 표시된다.

**기능**

- 저장: 팀명 변경
- 팀 삭제: 소속 선수가 없는 경우만 가능. 삭제 시 확인 다이얼로그(6.0.1) 표시

#### 6.4.4 선수 관리

팀 상세 화면에서 해당 팀의 선수를 관리한다.
헤더에 팀명과 설정(⚙️) 아이콘이 표시된다. 설정 아이콘을 탭하면 팀 수정 화면(6.4.3)으로 이동한다.

**선수 목록**

- 선수 이름은 "등번호. 이름" 형식으로 표시 (예: 0. 홍길동)
- 팀장인 선수만 이름 옆에 "팀장" 뱃지를 표시한다. 팀원은 별도 표시 없음.
- 각 선수 행에 수정(✏️), 삭제(🗑️) 아이콘 버튼이 표시된다.

#### 6.4.5 선수 추가 (관리자 전용)

선수 목록 화면에서 "선수 추가" 버튼을 탭하면 선수 추가 화면으로 이동한다. 헤더에 "선수 추가"가 표시된다.
상단에 가이드 텍스트를 표시한다. (예: "선수 등록", "여러 명의 선수를 한 번에 등록할 수 있습니다.")

**입력 항목**

- 선수별 입력 폼이 카드 형태로 표시된다. (선수 1, 선수 2, ...)
- 각 카드에 삭제(✕) 버튼이 표시된다.
- 하단에 "+ 선수 추가" 버튼으로 입력 폼을 추가할 수 있다.
- 여러 명의 선수를 한 번에 등록할 수 있다.

| 항목 | 타입 | 필수 |
|------|------|------|
| 이름 | 텍스트 입력 | O |
| 등번호 | 숫자 입력 | O |
| 역할 | 셀렉트 (팀장 / 팀원) | O |

**유효성 검사**

- 이름은 필수 입력
- 등번호는 0 이상의 정수
- 같은 팀 내에서 등번호 중복 불가

#### 6.4.6 선수 수정 (관리자 전용)

선수 목록 화면에서 수정(✏️) 아이콘을 탭하면 선수 수정 화면으로 이동한다. 헤더에 "선수 수정"이 표시된다.
입력 항목과 유효성 검사는 선수 추가(6.4.5)와 동일하며, 기존 데이터가 미리 채워진 상태로 표시된다.

#### 6.4.7 선수 삭제

- 삭제(🗑️) 아이콘을 탭하면 삭제 확인 다이얼로그(6.0.1)가 표시된다.
- 확인 시 선수가 삭제된다.

## 7. 데이터 모델

### 7.1 주요 테이블

#### teams

| 칼럼 | 타입 | 설명 |
|------|------|------|
| id | uuid (PK) | 팀 고유 ID |
| name | text | 팀명 |
| created_at | timestamp | 생성일시 |

#### players

| 칼럼 | 타입 | 설명 |
|------|------|------|
| id | uuid (PK) | 선수 고유 ID |
| name | text | 선수 이름 |
| number | integer | 등번호 (같은 팀 내 고유) |
| team_id | uuid (FK → teams) | 소속 팀 |
| role | text | 역할 (leader / member) |
| created_at | timestamp | 생성일시 |

#### matches

| 칼럼 | 타입 | 설명 |
|------|------|------|
| id | uuid (PK) | 경기 고유 ID |
| team_a_id | uuid (FK → teams) | 팀 A |
| team_b_id | uuid (FK → teams) | 팀 B |
| match_date | date | 경기 날짜 |
| match_time | time | 경기 시간 |
| location | text | 경기 장소 |
| team_a_score | integer | null | 팀 A 점수 (null = 미등록) |
| team_b_score | integer | null | 팀 B 점수 (null = 미등록) |
| created_at | timestamp | 생성일시 |

#### player_records

| 칼럼 | 타입 | 설명 |
|------|------|------|
| id | uuid (PK) | 기록 고유 ID |
| match_id | uuid (FK → matches) | 해당 경기 |
| player_id | uuid (FK → players) | 선수 |
| goals | integer | 득점 수 |
| assists | integer | 도움 수 |
| created_at | timestamp | 생성일시 |

### 7.2 관계도

```
teams ─┬─< players
       ├─< matches (team_a_id)
       └─< matches (team_b_id)

matches ─< player_records

players ─< player_records
```
